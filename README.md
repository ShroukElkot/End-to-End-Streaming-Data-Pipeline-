# End-to-End-Streaming-Data-Pipeline-
Developed an end-to-end real-time data lakehouse on Azure Databricks integrating APIs and Event Hubs to power curated Gold/Business layer views for downstream analytics. 
- Architected a real-time streaming Data Lakehouse on Azure Databricks (Medallion Architecture) to ingest and process live cryptocurrency data using PySpark and Event Hubs. 
- Engineered a statistical anomaly detection engine (using Z-scores and sliding windows) and loaded aggregated financial metrics directly into Azure Synapse for live Power BI dashboards.
